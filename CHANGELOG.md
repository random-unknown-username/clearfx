# Changelog

## 0.1.0 (2025-08-05)

Initial release.

- 36 built-in terminal animations
- Shell integration (bash, zsh, fish)
- Declarative `.clearfx` package format
- Community marketplace with safe sandboxed execution
- Recording support (SVG, asciicast, GIF)
- Configurable via `~/.config/clearfx/config.toml`
